# Solar System Arena

Landing shell for a four-agent coding challenge. The app has a home page and one assigned workspace page for each agent:

- `/codex`
- `/claude-code`
- `/grok`
- `/gemini`

Each workspace contains a dedicated blank canvas and mission bay for the future 3D solar-system simulation brief.

## Run

```bash
npm install
npm run dev
```
